# utf8.library

**UTF-8** text on a classic Amiga, as one shared library in `LIBS:`, from C and from **ARexx**.
UTF-8 is the text of the web, of mail and of every modern computer; the Amiga's own text is
Latin-1. This library sits between the two, so a program can count, measure, cut, search, compare
and convert UTF-8 without carrying its own tables.

Nothing like it existed for the 68k Amiga (2026-10): codesets.library converts between sets for
mail programs, but nothing counts characters and columns, moves a cursor, or searches without
case and accents across all of Unicode.

## What it does

| | |
|---|---|
| **Characters** | read and write one (`Utf8Decode`, `Utf8Encode`); count them as a reader does: a letter with its accents, a flag, an emoji family is one (`Utf8Length`) |
| **Columns** | how wide a text is on a terminal: Chinese, Japanese, Korean and emoji take two, accents none (`Utf8Width`, `Utf8CharWidth`); how much fits (`Utf8Fit`) |
| **Cursor** | to the next or previous whole character, for editors (`Utf8Next`, `Utf8Prev`) |
| **What a character is** | letter, digit, space, punctuation, accent, upper, lower, wide (`Utf8Class`) |
| **Case and accents** | upper and lower case in every script (`Utf8Upper`, `Utf8Lower`, `Utf8Case`); é to e, Ł to L (`Utf8NoAccent`) |
| **Search and compare** | with or without case and accents: "malmo" finds "Malmö" (`Utf8Find`, `Utf8Compare`) |
| **Mac file names** | å as one character or as a + ring, either way (`Utf8Normalize`); compared as the same everywhere |
| **14 character sets** | to and from Latin-1, Latin-2, Latin-9, Cyrillic, Greek, Turkish, Windows 1250/1251/1252, IBM 437/850/866, KOI8-R, Mac Roman, ASCII; by name (`Utf8Charset`); the nearest for what a set lacks: “ ” to ", € to EUR, box lines to + - \| |
| **Amiga text welcome** | a byte that is not UTF-8 is its Latin-1 letter, so Amiga text works in every call, unchanged |
| **ARexx** | `UTF8LEN`, `UTF8WIDTH`, `UTF8SUBSTR`, `UTF8UPPER`, `UTF8TO`, `UTF8FROM`, `UTF8FIND` and more, counting characters where ARexx counts bytes |
| **Unicode 16** | widths, case and classes for all 1,114,112 code points, checked against Python's Unicode database |
| **Small machines** | 68000 and up, no FPU, no recursion, under 0.5 KB of stack, nothing kept between calls; about 32 KB |

## For programmers

The [programmer's guide](docs/guide.md) explains how to use it, with a working first program and
ARexx examples; the [reference](docs/reference.md) describes every call in full.

```c
Utf8ToCharset(text, -1, shown, sizeof(shown), U8CS_LATIN1, 0);   /* UTF-8 on an Amiga screen */
cols = Utf8Width(text, -1);                                      /* 日本 is 4 columns */
pos = Utf8Find(text, -1, "goteborg", -1, U8F_NOCASE | U8F_NOACCENT, &len);
```

```rexx
CALL ADDLIB('utf8.library', 0, -30, 0)
SAY UTF8TO(UTF8UPPER(text))
```

## Building

`make` (bebbo's gcc): the library three times and `build/utf8test`. `make pctest` runs the core on
the PC under the address and undefined-behaviour sanitizers, `make pccheck` holds every code point
and every set against Python's own Unicode database and codecs, `make fuzz` runs it under
libFuzzer. `make tables` writes `src/tables.c` again from Python's Unicode database (for a new
Unicode version).

**Which library to install** as `LIBS:utf8.library`:

| File | For |
|---|---|
| `build/000/utf8.library` | 68000, 68010 (every Amiga) |
| `build/020/utf8.library` | 68020, 68030, 68040, Emu68 |
| `build/060/utf8.library` | 68060 (no 64-bit multiply or divide, which the 060 only emulates; runs on a 68040 too) |

No FPU build: the library does no floating point.

- AmigaOS 2.04+ tested; it calls only exec, so 1.3 should work (not tested). ARexx needs RexxMast
  running.
- The library has no C library inside (`-nostartfiles -nostdlib`); the build fails if libnix code
  gets in.
- **The table order is for ever.** `utf8.sfd` and `functable` in `src/lib.c` list the calls in
  the same order; new ones go at the end of both, and `UTF8_REVISION` goes up. The first entry is
  ARexx's and must stay first.

## Files

| File | What |
|---|---|
| `utf8.sfd` | the calls and their registers: the source of the headers |
| `include/libraries/utf8.h` | the constants |
| `include/proto/`, `inline/`, `clib/` | generated by `make headers` |
| `src/utf8.c` | all the work: plain C, also built on the PC |
| `src/tables.c` | the Unicode tables, written by `tools/gen.py` (do not edit) |
| `src/rexx.c` | the ARexx functions |
| `src/lib.c`, `src/start.s` | the library: Resident tag, jump table, ARexx's entry |
| `tools/gen.py`, `tools/check.py` | the tables from Python's Unicode database, and the check against it |
| `docs/guide.md`, `docs/reference.md` | the programmer's guide and the reference |
| `tests/unit.c`, `dump.c`, `fuzz.c` | the PC tests (`tests/pcinc` stands in for the Amiga headers) |
| `tests/utf8test.c`, `utf8test.rexx`, `first.c` | on the Amiga: every check through the library, and the speeds; the ARexx functions; the guide's first program |

## State

**0.1b1, 2026-10-17.** Tested:

- **On the PC:** 178 unit checks under ASan and UBSan; widths, case, classes and accent removal for
  all 1,114,112 code points, the 14 sets byte by byte, and NFC/NFD for Latin, Greek, Cyrillic,
  kana and Hangul, all equal to Python 3.14's Unicode 16.0; libFuzzer for about 50 minutes in all (five
  faults found and fixed on the way, all in comparing accents written in unusual ways).
- **In FS-UAE:** `utf8test` (the same 178 checks through the library) and `utf8test.rexx` all
  passed on the A1200 test machine (68EC020, OS 3.2.1, the 020 build), on the same machine as a
  68040 (the 020 and 060 builds) and as a 68060 (the 060 build), and on the A600 (68000,
  Workbench 2.05, the 000 build). The guide's first program ran as written.
- **Not yet:** the real A1200; a real 68040 or 68060; Kickstart 1.3.

**Next:** tui.library, CTerm, csh and the CUtils taking their UTF-8 work from here; Japanese and
emoji text faster (see the guide's [Speed](docs/guide.md#speed)).
